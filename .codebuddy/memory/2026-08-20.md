# 2026-08-20 工作日志

## 增量对比新增 CLI 命令

用户要求增量对比功能也要有 CLI 命令（之前只有 Web 页面版本）。

### 实现
- `weibo_im/export.py` 新增：
  - `_detect_format()` / `_parse_export_text()` / `_parse_export_csv()` — 文件解析（JSON 数组 / CSV，BOM、引号、字段内换行/逗号/引号转义兼容）
  - `compute_delta(old_rows, new_rows)` — 组合键差集：去重键 `(sender_name, text, 出现序号)`，旧包建 base->count，新包按序消费配额，超出为新增
  - `diff_export_files(old_path, new_path, output_path=None, fmt="json")` — 主入口，读两文件、求差集、写出补充包（utf-8-sig CSV / indent JSON），返回统计 dict（含 same_sender 前10条核对）
- `crawl.py` 新增参数：`--diff` / `--old` / `--new` / `--diff-format {json,csv}` / `--diff-output -O`，新增 `_do_diff()` 与 dispatch

### 用法
```
python crawl.py --diff --old 旧包.json --new 新包.json
python crawl.py --diff --old old.csv --new new.csv --diff-format csv -O delta.csv
```

### 测试结果
- 同格式/跨格式（旧CSV+新JSON）对比均正确
- 同文本多条（旧2新3→新增1）正确
- same_sender 前10条核对：修复了短包长度不等导致误报不一致的 bug（改为 min(10, len) 逐位比较）
- 缺 --old/--new 有清晰错误提示
- CSV 解析支持 BOM 前缀

### 注意
- 补充包格式与 `--export` 完全一致（JSON 数组 / CSV 表头 sender_name,text）
- 输出默认写入系统临时目录 delta_<时间戳>，可用 -O 指定
