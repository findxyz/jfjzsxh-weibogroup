# 导出增量对比（补充包生成）

把两次导出的数据包进行对比，自动得出"新包有、旧包没有"的新增消息，生成**补充包**，用于增量更新已上传到 AI 工具的数据，避免重复上传全量数据。

## 背景

群聊数据持续爬取，导出的内容会不断增加。若上月已把某成员的完整发言包上传到 NotebookLM，本月再次全量导出后，重新上传整个更新包成本很高。本功能通过对比两次导出，只提取新增部分作为补充包。

- **旧包**：上次导出的数据包（已上传过）
- **新包**：本次重新导出的数据包（包含旧包全部内容 + 新消息）
- **补充包**：新包中、旧包没有的消息，可直接追加上传

---

## 1. 去重逻辑

导出文件只有 `sender_name` 与 `text` 两列（不含 `mid`），因此以**组合键**去重：

```
去重键 = (sender_name, text, 出现序号)
```

- `出现序号`：同一个 `(sender_name, text)` 在同文件内第几次出现（从 0 递增）
- 旧包统计每个组合键出现的次数；新包按出现顺序消费旧包配额，**超出部分即为新增**
- 正确处理"同一文本发了多次"的场景：旧包发了 M 次、新包发了 K 次（K ≥ M），则新增 K − M 条

## 2. 同群同成员校验

导出文件不含 `gid` / `sender_id`，无法强制校验。功能在结果中展示**两包前 10 条 `sender_name`** 供肉眼核对：

- 一致 → 正常输出
- 不一致 → 日志警告，提示"请确认是同一群同一成员"

（同一份导出文件里发言者通常一致，看前 10 条足以判断。）

## 3. 格式兼容

- 输入：JSON（`[{sender_name, text}, ...]` 数组）或 CSV（`sender_name,text` 表头，UTF-8-SIG），**自动识别**，且旧包与新包格式可不同（如旧 CSV + 新 JSON 也能对比）
- 输出补充包：与 `--export` 格式完全一致（JSON 数组 / CSV），可直接上传 NotebookLM
  - CSV 输出带 UTF-8-SIG（BOM）前缀，Excel 打开中文不乱码

---

## 4. CLI 用法

```bash
# 基本用法（旧包 JSON + 新包 JSON），补充包默认写入临时目录
python crawl.py --diff --old 旧包.json --new 新包.json

# 指定补充包格式与输出路径
python crawl.py --diff --old old.csv --new new.csv --diff-format csv -O delta.csv

# 旧包与新包格式不同也能对比
python crawl.py --diff --old old.csv --new new.json --diff-format json -O delta.json
```

### 参数

| 参数 | 说明 |
|------|------|
| `--diff` | 启用增量对比模式 |
| `--old` | 旧数据包路径（上次导出，必填） |
| `--new` | 新数据包路径（本次导出，必填） |
| `--diff-format` | 补充包输出格式 `json`（默认）或 `csv` |
| `--diff-output` / `-O` | 补充包输出路径（默认 `系统临时目录/delta_<时间戳>.<ext>`） |

### 输出日志

```
旧包: 5 条 | 新包: 8 条 | 新增: 3 条 | 重复: 5 条
补充包已写入: /tmp/delta_20260820_1430.json
```

若两包前 10 条发言者不一致，额外输出警告：

```
两包前 10 条发言者不一致，请确认是同一群同一成员
```

## 5. Web 页面用法

页面路径：运行 `server.py` 后访问 `/export.html`，切到 **"增量对比"** Tab。

1. 左侧选 **旧数据包**（上次导出），右侧选 **新数据包**（本次导出）
2. 选择补充包格式（JSON / CSV，默认 JSON）
3. 点 **"开始对比"**
4. 结果区显示：旧包条数 / 新包条数 / 新增条数 / 重复条数，以及两包前 10 条发言者核对信息
5. 点 **"下载补充包"**，得到 `delta_YYYYMMDD_HHMM.<ext>` 文件

纯前端完成，不依赖后端 API、不读取数据库、不上传文件到服务器。

---

## 6. 典型工作流

1. 上月用 `--export` 导出某成员全部发言 → 上传 NotebookLM
2. 本月群聊更新后，再次用 `--export` 导出同一成员 → 得到"新包"
3. 用 `--diff --old 上月包 --new 本月包` 生成补充包
4. 把补充包追加上传到 NotebookLM，无需重传全量

---

## 7. 注意事项

- 对比基于 `(sender_name, text, 出现序号)` 组合键；若同一文本被不同成员发送，会按 `sender_name` 区分，不会误判为重复
- 旧包必须**包含**于新包（即新包是旧包的超集）才有意义；若新包比旧包少了某些消息，少的部分不会提示，仅多出的部分作为新增
- 不修改任何数据库、爬虫逻辑与现有导出格式
