# 每日群聊日报导出（CSV）

把指定群 + 成员 + 日期的当日群聊全部消息导出为 CSV，供后续交给 AI 生成成员当日群聊总结日报。

与 `--export`（仅导出本人发言）不同，`--daily` 会**连同群里其他成员当天的发言一起导出**作为上下文，AI 能看到当日群聊全貌，做出更准确的成员发言总结。

---

## 1. 功能说明

- **输入**：群 ID（`--gid`）、日期（`--date`）、目标成员（`--sender-id` 或 `--sender-name`）
- **输出**：CSV 文件（UTF-8-SIG 编码，Excel 可直接打开）
- **数据范围**：指定群在指定日期（CST 当日零点 ~ 次日零点）的全部用户发言（`msg_type` 100/321），自动排除系统消息（入群/撤回/通知等）
- **上下文**：当日群里所有发言成员的消息都会被导出，目标成员发言用 `is_target=1` 标记，其他成员（上下文）用 `is_target=0` 标记

### CSV 字段

| 列 | 类型 | 说明 |
|----|------|------|
| `created_at` | 字符串 | CST 时间字符串，格式 `YYYY-MM-DD HH:MM:SS` |
| `sender_name` | 字符串 | 发言者昵称 |
| `text` | 字符串 | 消息正文（含换行符的文本会被双引号包裹） |
| `is_target` | 整数 | `1`=目标成员发言，`0`=其他成员（上下文） |

### 文件命名

默认输出到项目根目录，命名规则：

```
daily_<gid>_<sender>_<YYYY-MM-DD>.csv
```

示例：`daily_4778124434997704_陈同辉-宏观策略_2026-07-26.csv`

可用 `-o` / `--output` 自定义输出路径。

---

## 2. 前置条件

- 数据库 `weibo_im.db` 已有目标群的历史消息（即已经用 `uv run crawl.py` 抓取过）
- 已知目标群的 `gid` 和目标成员的 `sender_id` 或昵称（不知道时按下面步骤查）

---

## 3. 使用步骤

### 第一步：查群列表（拿到 `gid`）

```bash
uv run python crawl.py --list-groups
```

输出示例：

```
已知的群（3 个）:
  gid=4778124434997704  成员=0     陈同辉-宏观策略的客服群
  gid=5211500894489005  成员=0     西医养生俱乐部
  ...
```

### 第二步：查群内成员（拿到 `sender_id` 或昵称）

```bash
uv run python crawl.py --list-members --gid 4778124434997704
```

输出示例：

```
群 4778124434997704 的发言成员（9 人）:
  sender_id=1401164841    发言=120   最近=2026-07-26 15:50:02  陈同辉-宏观策略
  sender_id=5394206608    发言=85    最近=2026-07-26 14:22:10  粉丝群
  ...
```

### 第三步：导出日报 CSV

**用 `--sender-id`（推荐，不受改名影响）：**

```bash
uv run python crawl.py --daily --gid 4778124434997704 --date 2026-07-26 --sender-id 1401164841
```

**用 `--sender-name`（按昵称，程序会自动反查 sender_id）：**

```bash
uv run python crawl.py --daily --gid 4778124434997704 --date 2026-07-26 --sender-name "陈同辉-宏观策略"
```

**自定义输出路径：**

```bash
uv run python crawl.py --daily --gid 4778124434997704 --date 2026-07-26 --sender-id 1401164841 -o D:\out\report.csv
```

### 第四步：查看导出结果

控制台输出示例：

```
已导出日报 18 条消息 → daily_4778124434997704_陈同辉-宏观策略_2026-07-26.csv
群聊: 陈同辉-宏观策略的客服群
日期: 2026-07-26
目标成员: 陈同辉-宏观策略 (sender_id=1401164841)
  本人发言: 5 条
  上下文消息: 13 条
```

CSV 文件内容示例：

| created_at | sender_name | text | is_target |
|---|---|---|---|
| 2026-07-26 08:33:34 | 用户7570982524 | hi，早上好！ | 0 |
| 2026-07-26 09:12:05 | 陈同辉-宏观策略 | 大家注意今天的数据 | 1 |
| 2026-07-26 09:15:20 | 粉丝群 | 收到 | 0 |
| ... | ... | ... | ... |

### 第五步：交给 AI 生成日报

把生成的 CSV 文件内容喂给 AI，配合提示词（例如）：

> 请根据以下群聊记录，总结成员「陈同辉-宏观策略」在 2026-07-26 的发言要点。
> CSV 中 `is_target=1` 的行是该成员本人发言，`is_target=0` 的行是群聊上下文。
> 请结合上下文理解该成员发言的背景与意图，输出结构化的当日群聊日报。

---

## 4. 参数说明

| 参数 | 必选 | 说明 |
|------|------|------|
| `--daily` | 是 | 启用日报导出模式 |
| `--gid GID` | 是 | 群 ID |
| `--date DATE` | 是 | 日期，格式 `YYYY-MM-DD` 或 `YYYY/MM/DD`（CST 当日） |
| `--sender-id ID` | 二选一 | 目标成员的 sender_id（推荐，稳定） |
| `--sender-name NAME` | 二选一 | 目标成员昵称（程序会反查 sender_id） |
| `-o` / `--output PATH` | 否 | 自定义输出路径（默认 `daily_<gid>_<sender>_<date>.csv` 在项目根目录） |
| `--db PATH` | 否 | 指定数据库路径（默认 `weibo_im.db`） |

---

## 5. 注意事项

1. **时区口径**：日期按 **CST(+08:00)** 当日零点切分，不论系统时区如何都一致。
2. **`--sender-id` 优于 `--sender-name`**：昵称可能因改名漂移，`sender_id` 更稳定。用昵称时程序会取该群内该昵称最近一条发言的 `sender_id` 作为目标标识。
3. **仅含用户发言**：系统消息（入群 `msg_type=322`、撤回等）自动过滤，只保留普通消息(321)与微博分享(100)。
4. **目标成员当日无发言**：CSV 仍会导出（含当日群聊上下文，`is_target` 全为 0），控制台会给出警告，便于核对日期/成员是否正确。
5. **`--daily` 与 `--export` 区别**：
   - `--export`：仅导出目标成员本人发言（`sender_name,text` 两列），无上下文。
   - `--daily`：导出当日群全部用户发言（`created_at,sender_name,text,is_target` 四列），含上下文，专为 AI 生成成员日报设计。
