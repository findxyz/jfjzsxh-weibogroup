### 上传格式决策（用户反馈 mid 浪费 AI token）
- **关键**：水位线 max_mid 由导出命令返回值提供，**与文件列无关**，mid 不必进上传文件。
- 上传知识库用 `--slim`：输出 `created_at,text`（保留宏观策略时效性，去 mid + 冗余 sender_name）。
- `--with-meta`（mid,created_at,sender_name,text）仅本地核验用。
- 体积：696K(with-meta) → 523K(slim)，-25%，砍约 12.8 万字符。
- 命令：`uv run python crawl.py --export --gid 4778124434997704 --sender-id 1401164841 --watermark-file _chen/.watermark.json --slim --format csv -o _chen/delta_<日期>_slim.csv`

### 可复用月度命令（uv run）
```
# 1. 爬最新（cookie 失效先 --renew-cookie）
uv run python crawl.py
# 2. 增量导出（自动读水位线）
uv run python crawl.py --export --gid 4778124434997704 --sender-id 1401164841 \
  --watermark-file _chen/.watermark.json --with-meta --format csv -o _chen/delta_<日期>.csv
# 3. 上传 ima（agent 侧 create_media→add_knowledge）
# 4. 推进水位线（上传成功后）
uv run python -c "from weibo_im.export import write_watermark; write_watermark('_chen/.watermark.json','<本批max_mid>',note='...')"
```
